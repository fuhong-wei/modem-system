# 可靠 UDP 文件传输与调制解调系统

一个基于 [Streamlit](https://streamlit.io/) 的交互式通信系统演示，集成了数字调制解调、信道编码和基于 UDP 的可靠文件传输，并提供误码率（BER）分析与信号可视化。

## 功能特性

- **调制解调**：BPSK 调制与解调
- **信道编码**：重复编码 (1,3) 与汉明编码 (7,4)，支持错误检测与纠正
- **可靠 UDP 传输**：数据分块、滑动窗口、超时重传与 CRC 校验，在不可靠的 UDP 之上实现可靠文件传输
- **误码率分析**：模拟与实际传输的误码率计算、比特错误定位
- **信号可视化**：星座图、频谱分析、时域波形对比
- **中文界面**：发送文件 / 接收文件 / 误码率分析 三个页签

## 环境要求

- Python 3.8+
- 依赖库见 `requirements.txt`

## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

启动 Streamlit 应用：

```bash
streamlit run app.py
```

启动后浏览器会自动打开界面：

1. **发送文件**：设置目标 IP 与端口，选择要发送的文件
2. **接收文件**：在接收端监听对应端口，接收并保存文件
3. **误码率分析**：调整调制方式、编码方案与信噪比，观察误码率变化与信号波形

## 主要模块

- `ModemSystem`：调制解调与编解码核心（BPSK、重复编码、汉明编码、误码率计算）
- `ReliableUDPTransfer`：基于 UDP 的可靠传输（分块、滑动窗口、重传机制）
